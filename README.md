# أداء فريق العز

نظام متابعة شغل فريق التسويق في العز للعود: دورة المؤثر (6 مراحل)، الطلبات بين الأدوار، تقرير اليوم، ولوحة الأداء.

- الواجهة: ملفات ثابتة على GitHub Pages (`index.html`، `intake.html`، `assets/`).
- البيانات: Supabase (PostgreSQL) بصلاحيات على مستوى الصف (RLS). الجداول في `supabase/schema.sql`.
- رابط المؤثر `intake.html?t=…` يعبّي فيه المؤثر عنوانه وحسابه البنكي بدون تسجيل دخول، والبنك يتشفّر في المتصفح بمفتاح المدير العام.
- نسخة احتياطية يومية الساعة 12:40 الظهر في مجلد «نظام فريق العز» على OneDrive.
